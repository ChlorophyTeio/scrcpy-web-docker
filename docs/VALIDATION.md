## 实体屏幕状态回归（2026-11-07）

修正了三条隐式亮屏路径：投屏启动的 `power_on`、快捷控制绕过参数解析时的默认亮屏，以及 scrcpy 退出清理时的恢复亮屏。ADB 模式的临时 JAR 仍由 agent 在进程结束后回收，下次连接也会清理残留。

新增回归覆盖快捷控制、后台预览、摄像头、正常连接及本机/ADB 两种模式的断开行为。Go 全量测试通过，amd64 通用镜像已部署。实测 WebRTC 收到视频帧，游戏启动、MaaCore 原生连接、MAA 分辨率准备/恢复和连续两次重连均保持实体屏幕关闭；手动亮屏及熄屏仍可用。另外验证了关闭所有浏览器后单独进行 MAA 原生连接，准备和恢复阶段也保持熄屏。测试没有启动消耗理智的游戏任务。

## 双向剪贴板联动（2026-11-07）

默认开启联动，保留用户明确关闭的选择。控制端在浏览器权限允许且页面处于前台时检测剪贴板变化；复制事件与切回页面也触发同步。手机文字写入控制端失败时保留最新待同步值，提供显式用户点击的复制入口。首次读取只建立基线，不因打开页面而覆盖已有手机剪贴板。联动不自动把文字粘贴进手机输入框；Ctrl+V 才执行粘贴，Ctrl+C 请求手机 COPY 并读取结果。

46 项前端测试通过，新增覆盖回传去重、背景队列、权限失败重试、过期本机读取、并行写入合并、禁用和复制事件选区。Go agent 测试验证 COPY 与普通读取的协议字节及非法值拒绝。Chromium 实际双向剪贴板、后台补同步、权限失败保留/点击重试、关闭联动和快捷键请求通过，测试后确认恢复原手机剪贴板。Firefox 验证不进行反复读取提示，保留手动粘贴及手机端联动界面。
