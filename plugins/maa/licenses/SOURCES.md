MAA plugin worker and GUI additions: Apache-2.0 / frontend MIT as described in repository NOTICE.

Official programs run as independent subprocesses:
- maa-cli v0.7.7: https://github.com/MaaAssistantArknights/maa-cli/tree/v0.7.7
- MaaCore: downloaded at first launch, not included in this build. Matching sources and release information: https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases
- MaaResource: https://github.com/MaaAssistantArknights/MaaResource

The image retains the upstream license texts. CLI archives are SHA256-verified. Core versions and resources are managed by the worker's version/resource settings and persisted outside the image.
